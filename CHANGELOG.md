# Changelog

All notable changes to Reveal. Versions before 0.37.0 are the Swift app; from 0.37.0 on it is the Rust + Tauri rewrite.
Backfilled from git history; newer entries are generated by `scripts/release.mjs`.

## 0.46.2 — 2026-10-02

### Fixed

- Reveal now starts on any Mac. 0.46.0 and 0.46.1 depended on libraries that only exist where Homebrew has installed them, so they would not launch anywhere else.
- Connecting a Garden account is safer: Reveal only accepts a sign-in that it started itself, so a link from a web page can no longer swap in someone else's account.
- Each Mac you connect to Garden gets its own key, so connecting a second one no longer signs the first out.
